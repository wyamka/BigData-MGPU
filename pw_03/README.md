**Бизнес-кейс.** Компания **HealthTech** (аналог Endomondo/Strava).

## Ключевые технические решения

### Feature Engineering (Задание 1)

`avg_heart_rate` — среднее значение пульса по всей тренировке. Отражает общую интенсивность нагрузки.
`duration` — длительность тренировки.

Целевая переменная формируется синтетически:

`calories` — рассчитывается по формуле:
`duration * avg_heart_rate / 100`
Используется как приближённая оценка энергозатрат.

### Моделирование: Linear Regression (Задание 2)

Решается задача регрессии — предсказание количества сожжённых калорий.

Используется модель линейной регрессии, предполагающая линейную зависимость между признаками и целевой переменной.
Модель обучается на сформированных признаках:

`duration`
`avg_heart_rate`

### Оценка качества и интерпретация (Задание 3)

Для оценки модели используются метрики:

`RMSE (Root Mean Squared Error)` — показывает среднюю ошибку предсказания в тех же единицах, что и целевая переменная
`R² (коэффициент детерминации)` — отражает долю объяснённой дисперсии
